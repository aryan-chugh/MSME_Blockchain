## 📝 Maintenance Guidelines

### Adding New Documentation
1. Determine category (guides/testing/architecture/deployment)
2. Create file in appropriate folder
3. Update [docs/README.md](docs/README.md) index
4. Cross-reference from other relevant docs

### Updating Existing Docs
1. Find authoritative source
2. Update in-place
3. Update cross-references if needed
4. Move to archive if obsolete

### Archiving Old Docs
1. Move to [docs/archive/](docs/archive/)
2. Remove from index
